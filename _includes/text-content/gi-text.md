<p>
  The Qiu Lab builds open-source software for single-cell and spatial genomics,
  from the analysis packages that helped establish the field's methods to a new
  generation of AI-native platforms.
</p>

<p class="software-list-label">AI-native platforms</p>
<ul class="software-list">
  <li>
    <a href="https://pantheonos.stanford.edu/">PantheonOS</a>
    <span class="software-item-tagline">the AgentOS for biological discovery</span>
    <ul class="software-sublist">
      <li>An evolvable, privacy-preserving multi-agent framework for automatic genomics discovery.</li>
      <li>LLM-powered agents collaborate on specialized scientific tasks, reconciling general-purpose reasoning with deep domain specificity.</li>
      <li>A four-layer architecture: application, interface, agent, LLM.</li>
      <li>The Pantheon Store offers 2,000+ curated biomedical agents, teams and skills.</li>
    </ul>
  </li>
  <li>
    <a href="https://biobabel.stanford.edu/">Bio-Babel</a>
    <span class="software-item-tagline">the classics of bioinformatics, in more than one tongue</span>
    <ul class="software-sublist">
      <li>Rebuilds classic tools natively in a new language rather than bridging to them at runtime, so they can be extended and composed, not merely called.</li>
      <li>Every package ships a machine-readable contract, so an agent that has never seen it still calls it correctly.</li>
      <li>17 libraries live on PyPI, 1,606 contracted symbols, zero runtime bridges.</li>
    </ul>
  </li>
</ul>

<p class="software-list-label">Analysis packages</p>
<ul class="software-list">
  <li>
    <a href="https://github.com/aristoteleo/spateo-release">Spateo</a>
    <ul class="software-sublist">
      <li>Multiscale modeling of spatial genomics, from subcellular to whole embryo.</li>
    </ul>
  </li>
  <li>
    <a href="https://github.com/aristoteleo/dynamo-release">Dynamo</a>
    <ul class="software-sublist">
      <li>Predicts cell-fate transitions, optimal reprogramming factors and <i>in silico</i> perturbations.</li>
    </ul>
  </li>
  <li>
    <a href="https://github.com/aristoteleo/dynast-release">Dynast</a>
    <ul class="software-sublist">
      <li>Efficient quantification for metabolic-labeling scRNA-seq.</li>
    </ul>
  </li>
  <li>
    <a href="https://github.com/cole-trapnell-lab/monocle-release">Monocle 2/3</a>
    <ul class="software-sublist">
      <li>Infers developmental trajectories from single-cell data.</li>
    </ul>
  </li>
  <li>
    <a href="https://github.com/aristoteleo/Scribe-py">Scribe</a>
    <ul class="software-sublist">
      <li>Learns causal gene-regulatory networks.</li>
    </ul>
  </li>
  <li>
    <a href="https://github.com/aristoteleo/">Aristotle</a>
    <ul class="software-sublist">
      <li>The end-to-end ecosystem tying these together for quantitative spatiotemporal modeling.</li>
    </ul>
  </li>
</ul>

<p class="software-provenance">

</p>
